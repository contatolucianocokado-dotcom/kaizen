# Graphify - Kaizen

Este arquivo deve receber o mapa mental gerado pelo Graphify.

Ao compartilhar publicamente, revisar e remover:

- senhas;
- tokens;
- hosts privados sensiveis;
- credenciais OAuth;
- dados pessoais;
- logs com segredos.

## Regra

Sempre consultar o mapa antes de alterar o sistema e atualizar o mapa apos modificacoes relevantes.
