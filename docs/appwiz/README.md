# app.wiz

Documentos de implantacao e evolucao recuperados do `app.wiz`.

Pontos principais ja estabelecidos:

- Todo erro real deve ser registrado.
- Todo risco previsivel deve ser registrado antes da acao.
- Todo agente deve consultar erros e riscos abertos antes de executar.
- Erro recorrente vira regra de aprendizado para os agentes aplicaveis.
- Construtores so entregam depois de auditoria independente.
- Auditoria minima: `95`; areas criticas podem exigir `98`.
- Reprovacao obriga refazer ate passar.
- Automacoes financeiras ou externas exigem autoridade configurada, evidencia e validacao.

Use esta pasta como referencia para consolidar o `app.wiz` no projeto Kaizen sem expor credenciais.
