# Google Ad Manager

## Chaves-valor essenciais

- `utm_source`
- `utm_medium`
- `utm_campaign`
- `utm_term`
- `utm_content`
- `utm_creative`

## Relatorios necessarios

- Site;
- Bloco de anuncio;
- Chaves-valor;
- Receita do Ad Exchange;
- Impressoes do Ad Exchange;
- Impressoes nao preenchidas;
- Taxa de correspondencia;
- eCPM;
- Cliques.

## Regra de atribuicao

O ID usado pelo Kaizen deve ser o ID real recebido pelo GAM.

Nunca remapear receita GAM de um ID para outro.
